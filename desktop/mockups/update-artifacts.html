Screen 2 · Update available

The popover after a new version is detected

Detection is a lightweight HTTPS probe to update.electronjs.org — it learns the version and release notes without downloading. The popover shows the new version, the release notes as plain text, a What's new link (opens the GitHub release page in the system browser), and a primary Download update action.

Screen 3 · Download & apply

The popover through the rest of the lifecycle

Squirrel.Windows downloads and stages in one step and emits no byte progress, so downloading is an indeterminate bar — honest about what the platform reports. When the package is staged the action becomes Restart to update (quitAndInstall()); Squirrel also applies it on the next normal quit. Any probe or download failure lands in error — surfaced, never fatal, with a Try again.

Screen 4 · Settings ▸ Updates

The full Updates section

Flat, cardless, content-first — rows sit directly in the page, separated by hairline dividers. It carries the current version, a live status line with a contextual action, and three per-device toggles that round-trip to the main process so it actually drives autoUpdater.

Screen 5 · Unsupported

On macOS, Linux, and dev builds

Auto-update ships only for the packaged Windows build (the release job is Windows-only, and Squirrel.Mac needs signing + notarization). Elsewhere the indicator stays hidden and the Settings section shows a plain, muted note instead of live controls — the surface stays inspectable without pretending to update.
