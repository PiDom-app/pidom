Screen 5 · Import queue

A header activity indicator opening a queue Popover

A compact indicator (spinner + active count, a warning dot when something failed) sits in the header controls. Clicking it opens a Radix Popover listing every active and failed job with per-file progress — byte percentage while a PDF uploads to the cloud — and Retry / Cancel per row. It fits the floating shell without a docked panel.

Screen 6 · Duplicates

Already-in-library files — skipped quietly, with a way back

A byte-identical re-import is skipped rather than duplicated. The tile reads Already in library in an ok tone (not an error), a batch-summary toast tallies the run, and a Details Popover per skipped file offers Open existing or Import a copy anyway — the copy re-imports under a fresh id, a distinct document that shares the same bytes.
