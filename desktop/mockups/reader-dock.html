The reader toolbar moves off the top edge and becomes a floating, bottom-centred macOS-style dock. Actions are grouped into clusters — navigate · page · zoom · layout · tools — with a hairline divider between clusters and no gap inside a cluster. A single gliding pill sits under the active layout mode and slides to the newly chosen mode. Solid surface, one border, 6px corners, soft drop shadow; no glass, blur, or gradient. Click the layout icons in screen 1 to watch the pill glide.

An environment is a sequence of frames. Each frame is a table of bindings, which associate variable names with their values. Each frame has a pointer to its enclosing environment.

The value of a variable with respect to an environment is the value given by the binding of the variable in the first frame that contains one.
