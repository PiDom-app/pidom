Fallback covers
Import renders the real first page now, so this is the fallback: a document imported before that existed, one whose render failed, or one whose cover has not reached this device yet. The tint is a pure function of the document id — twelve buckets thirty degrees apart, anchored on the brand hue — so the same document is the same colour on every device, for as long as it exists.
hue = ({{base}} + hash(id) % 12 × 30) mod 360  ·  dark oklch(.295 .062 h)  ·  light oklch(.925 .045 h)
