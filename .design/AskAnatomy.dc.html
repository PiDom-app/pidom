1
A route, not a sheet
A transcript’s height is the reader’s data and a composer is a control, which is the pair docs/design.md says must not be attached to each other. The navigator became a route for the same reason; pinning a sheet to 70% was living with the problem.
2
Pushed, so the document stays
The reader is one screen behind this, still mounted. Coming back is not reopening a 400-page file — which is why navigator and bookmark are pushed rather than presented too.
3
The composer owns the bottom
It is absolute bottom-4 and rides the keyboard on a shared value from KeyboardProvider. On a whole screen that is simply where it sits; in a sheet it was competing with the sheet for the same last few hundred pixels.
4
No bubbles
There are no cards in this application and one accent colour in it. A turn is a role label over a paragraph — the typography every Section heading already uses.
5
Citations are controls
Each goes to its page and drops back to the reader. An answer nobody can check against the book is an answer about a book rather than from one.
6
Two actions, both wired
Keep writes an annotation through the path a selected passage already takes, so it outlives the month. Copy copies. The component ships a third slot and it is empty rather than decorative.
